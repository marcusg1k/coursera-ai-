What is a prompt?
A prompt is an input that produced the desired output. 
Prompt can also be a series of instructions. 

example: 
write a small paragraph describing your holiday destination
or
write HTML code to generate a dropdown selection of cities within an online form

Series of instructions example using prompt: 
write a short story about a scientist on mars. 
what were some of the challenges he faced during his research? 


Power of generative AI models: 
output produced by generative AI models closely resembles that of humans. Relevant, Contextual, Imaginative, Nuanced, Accurate
The critical factor of generating such output is prompt. 

Correct vs incorrect prompts:

incorrect: sunset image between 2 mountains
correct: Generate an image depicting a calm sunset above a river valley that ress amidst mountains

building blocks of a well-constructed prompt
instructions: give distinct guidelines
context: provides a framework for generating relevant content
input data: any piece of information provided as part of prompt
output indicator: offers benchmarks for assessing attrubutes of the output

recap: a prompt is any input or series of instructions used to produce a desired output
these instrcutions help in directing the creativity of answers

writing proper prompts: 
four essential domains:
clarity, context, precision, role-play/persona pattern
